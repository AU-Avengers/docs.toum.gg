# Steam

This guide requires that you own _Among Us_ on [Steam](https://store.steampowered.com/app/945360).

---

:::danger[Downgrading is required]

Town of Us: Mira does not yet run on the latest version of Among Us. You must downgrade your base game before following the mod installation stops.

:::

> **1.** Right-click Among Us on Steam, then click **Properties**.
>
> **2.** Click **Betas** and select `public previous`.
>
> Steam should then automatically update the game version to v18.

---

### Mod Installation

> **1.** Download the latest [**steam-itch.zip**](https://github.com/AU-Avengers/TOU-Mira/releases/latest) folder for Town of Us: Mira.
>
> **2.** Go to your Steam library, right-click _Among Us_ and click **Manage** > **Browse Local Files**
>
> **3.** In File Explorer, navigate to the `common` folder and duplicate your _Among Us_ folder. Rename it to something like **Among Us - TOU Mira**.
>
> **4.** Extract the contents of the .zip folder you downloaded and open it. Copy all the contents and paste them into the new TOU Mira folder. It should look like this example:
>
> <img src={useBaseUrl('/img/Install/steammira.png')} />
>
> **5.** Launch the _Among Us.exe_ from that folder. If successful, it will launch with the **Town of Us: Mira** logo displayed in the top-left corner.
