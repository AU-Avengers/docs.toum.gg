## Town of Us: Mira has updated to [v1.7.1](https://github.com/AU-Avengers/TOU-Mira/releases/tag/1.7.1)!

This update includes bug fixes and some rolechanges. See the full changelog below.

:::danger[IMPORTANT]

<big>**This update runs on **v17.4** of Among Us and requires a fresh install.**</big>

Do not just replace files as this will cause issues.
:::

{/* truncate */}

### Changelog

<details className="customdetails">
  <summary>**Role & Modifier Bugfixes**</summary>

<details className="customdetails">
<summary>**Crewmates**</summary>
- Lookout shuffles its watch findings properly again.
- Seer Reveal mode checks its options properly.
- Converted Jailor no longer leaves jailee in a broken state.
- Knighted Mayor no longer gets double votes.
- Imitator no longer shows (Imi) while dead.
</details>

<details className="customdetails">
<summary>**Impostors**</summary>
- Ambassador retrain is consistently functional on teammates now.
- Ambassador retrain no longer sets the trainee's kill cooldown to 0.
- Traitor no longer shows (Traitor) while dead.
</details>

<details className="customdetails">
<summary>**Neutrals**</summary>
- Executioner, Fairy, and Inquisitor check for disconnected targets properly.
- Fixed errors thrown by unshattered Medusa stones that broke the whole game.
</details>

<details className="customdetails">
<summary>**Modifiers**</summary>
- Celebrity shows death by the Spectre properly.
- Circumvent uses are no longer bypassed with a meeting.
</details>
</details>

<details className="customdetails">
<summary>**Draft Mode & Other Bug Fixes**</summary>

<details className="customdetails">
<summary>**Draft Mode Bug Fixes**</summary>
- Draft no longer softlocks if Host disconnects.
- Draft UI is no longer left behind during role intro or when leaving mid-draft.
- Alignment Mode no longer shows the actual faction instead.
</details>

<details className="customdetails">
<summary>**Other Bug Fixes**</summary>
- End Game Summary shows role icons for disconnected players.
- Fixed the biggest source of memory leaking.
- Fixed crashing for Epic Games and Xbox Game Pass users.
- Game Options should no longer desync when initially joining.
</details>
</details>

<details className="customdetails">
  <summary>**Changes**</summary>

<details className="customdetails">
<summary>**Crewmate Changes**</summary>
- Prosecutor now stops swaps from happening.
- Monarch can now optionally reveal knighting in the meeting.
</details>

<details className="customdetails">
<summary>**Impostors Changes**</summary>
- Venerer can now cancel their ability early.
</details>

<details className="customdetails">
<summary>**Neutrals Changes**</summary>
- Victims of Executioner Torment, Jester Haunt, and Spectre Spook are publicly announced.
</details>

<details className="customdetails">
<summary>**Other Changes**</summary>
- Added Role Icon on Role Reveal screen local toggle.
</details>

</details>
