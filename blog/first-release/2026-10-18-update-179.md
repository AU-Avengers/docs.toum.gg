## Town of Us: Mira has updated to [v1.7.9 Beta 1](https://github.com/AU-Avengers/TOU-Mira/releases/tag/1.7.9-beta1)!

This update includes bug fixes and additional changes. See the full changelog below.

:::info[version change]

<big>**This update runs on **v19** of Among Us and requires a fresh install!**</big>

:::

{/* truncate */}

### Changelog

<details className="customdetails">
  <summary>**Role Bugfixes**</summary>

<details className="customdetails">
<summary>**Impostors**</summary>
- Ambusher's animation no longer breaks.
- Fix Parasite not being able to open meeting chat.
- Fixed Escapist recall sprite layering.
- Fixed Miner vent layering.
</details>

<details className="customdetails">
<summary>**Neutrals**</summary>
- Fixed "frozen" stones not actually appearing as stone.
- Chef keeps track of disconnected served players to prevent an impossible win.
</details></details>

<details className="customdetails">
<summary>**Other Bug Fixes**</summary>
- Disable Submerged button for Ghostwalkers.
- Fixed loading issues with Submerged. Note that this means every player is required to have it when using it.
- Fixed issues with draft not giving roles or simply not listening to other player picks.
- Fixed map decoration on Skeld.
- Fixed save data not saving.
</details>

<details className="customdetails">
  <summary>**Improvements, Additions & Changes**</summary>

<details className="customdetails">
<summary>**Improvements**</summary>
- Ambassador's Selection menu now has two circles of roles to display more at once.
- Zoom is no longer easy to trigger on mobile.
- Prevent zooming in draft.
- Fix issues with custom text icons clipping in UI.
</details>

<details className="customdetails">
<summary>**Balancing Tweaks**</summary>
- By default, Hunter will need to wait a round before they can kill a caught player without being punished for it if they are crew.
</details>

<details className="customdetails">
<summary>**Additions**</summary>
- Added implementation for the new match info guide, as well as a temporary toggle.
- Added the ability to see chat notifications outside of the lobby.
- Added settings to toggle sabotages when dead and when too few players are alive.
- Added Achievements Support (bundled in this release).
  Added basic Mutually-Exclusive role buckets.
</details>

<details className="customdetails">
<summary>**Changes**</summary>
- Rainbow color is a bit slower and is more optimized now.
- Added Nameplates and Visor support via Corsac Cosmetics, requiring it for all future releases.
- Removed Classic Mode for Players. Innersloth's changes have made it unfeasible to try getting it to work again.
</details></details>
