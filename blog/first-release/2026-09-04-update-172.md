## Town of Us: Mira has updated to [v1.7.2](https://github.com/AU-Avengers/TOU-Mira/releases/tag/1.7.2)!

This update includes bug fixes and additional changes. See the full changelog below.

:::info[version change]

<big>**This update runs on **v18** of Among Us and requires a fresh install!**</big>

:::

{/* truncate */}

### Changelog

<details className="customdetails">
  <summary>**Role & Modifier Bugfixes**</summary>

<details className="customdetails">
<summary>**Crewmates**</summary>
- Haunter: Dead killers no longer get an arrow to a revealed Haunter.
- Deputy: No longer guessable after being revealed.
- Prosecutor: Prosecute uses text is no longer broken.
- Time Lord: Final evil being revived no longer ends the game with a crewmate win.
- Swapper: Swapped players properly carry over their colorblind text.
</details>

<details className="customdetails">
<summary>**Neutrals**</summary>
- Doomsayer: If Doomsayer continues the game and is supposed to win the game when all guesses are completed, the game will no longer end in a crewmate win.
- Doomsayer: Guess information is properly tracked for other players.
- Plaguebearer: Pestilence transformation is fixed for edge cases.
</details>

<details className="customdetails">
<summary>**Modifiers**</summary>
- Deadly Quota: The last kill of the game is properly counted towards the quota now.
- Overclocker: Overclock no longer grants impostors a 0 second kill cooldown.
- Tiebreaker: Tiebreaker no longer continues the game while dead.
- Noisemaker: Noisemaker no longer stays lingering even when a body is cleaned up.
- Bait: Fixed bait reports occurring even if a body was cleaned up in time.
</details></details>

<details className="customdetails">
<summary>**Draft Mode & Other Bug Fixes**</summary>

<details className="customdetails">
<summary>**Draft Mode Bug Fixes**</summary>
- Amount of choices is no longer affected by the number of players present.
- Shuffling no longer reduces the number of options you get.
</details>

<details className="customdetails">
<summary>**Other Bug Fixes**</summary>
- Concealed changes such as Ambusher, Morphling, and Swooper no longer carry into meetings.
- Added support for the latest Level Imposter release.
- Fixed broken Submerged patching.
- Neutral Killers no longer take full priority over win conditions. This now fixes game draws.
</details>
</details>

<details className="customdetails">
  <summary>**Changes**</summary>

<details className="customdetails">
<summary>**Notable Changes**</summary>
- Mod now runs on Among Us v18.0.x.
- Prosecutor, Politician, Mayor, and Hypnotist have now switched to the new meeting abilities system.
- The Win Condition system has been rewritten. Neutral Benigns are treated as majority Crewmates if at least two main factions (Crew, Imps, NKs) exist. Otherwise, they will be ignored from win checks. Survivor can also win solo if only NBs remain.
- Vampire is counted as two Neutral Killing slots under Draft Mode now.
</details>

<details className="customdetails">
<summary>**Other Changes**</summary>
- By default, Janitor can clean and kill separately only if they're by themselves.
- Mayor and Deputy will still say their role on their name even if they are converted.
</details>

</details>
