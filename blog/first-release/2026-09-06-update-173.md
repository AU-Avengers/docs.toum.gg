## Town of Us: Mira has updated to [v1.7.3](https://github.com/AU-Avengers/TOU-Mira/releases/tag/1.7.3)!

This update includes bug fixes and additional changes. See the full changelog below.

:::info[version change]

<big>**This update runs on **v18** of Among Us and requires a fresh install!**</big>

:::

{/* truncate */}

### Changelog

<details className="customdetails">
  <summary>**Role Bugfixes**</summary>

<details className="customdetails">
  <summary>**Crewmates**</summary>
- Sheriff: Fixed broken punishment explanation in tab description.
- Altruist: Fixed broken tab description.
- Mirrorcaster: Magic Mirrors no longer stay permanently if the Mirrorcaster is converted.
</details>

<details className="customdetails">
  <summary>**Impostors**</summary>
- Morphling: If configured, the Morph ability uses are no longer able to go less than 0.
</details>

<details className="customdetails">
  <summary>**Neutrals**</summary>
- Survivor: Survivor no longer takes wins away from Impostors.
- Plaguebearer: Adjusted checks to rule out the possibility of duplicate plague on a player.
- Werewolf: Werewolf's short-burst kill cooldown is no longer affected by cooldown changes.
- Chef: Added safeguards against the possible occurrence of missing dead bodies, breaking the win conditions.
</details></details>

<details className="customdetails">
<summary>**Draft Mode & Other Bug Fixes**</summary>

<details className="customdetails">
  <summary>**Draft Mode Bug Fixes**</summary>
- Target-based roles like Fairy and Executioner have targets assigned properly again.
- Concurrent picks no longer removes picks from other player.
</details>

<details className="customdetails">
  <summary>**Other Bug Fixes**</summary>
- Fixed bad AU code causing anti-cheat to kick non-hosts if they voted for someone who died in the meeting.
- Fixed non-classic roles appearing in the settings menu.
- Fixed missing causes of death appearing due to locale system changes.
- Fixed Assailant Modifier Options text.
- Fixed kill cooldown for Impostors not being based on overall cooldown offsets.
</details></details>

<details className="customdetails">
  <summary>**Changes**</summary>

<details className="customdetails">
  <summary>**Other Changes**</summary>
- Added Ghostwalker Auto-Venting setting upon spawning under Game Mechanics.
- Added Judge's punishment as a setting for Prosecutor's punishment (now the default).
- Reshuffling in Draft Mode gives you spare time to pick if necessary.
</details></details>
